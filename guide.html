👷‍♂️ מנהל פרויקט — היום שלך באפליקציה

למעלה יש שלוש לשוניות: בקרה שטח מלאי.

☀️ כל בוקר — עד 08:00

  1. בקרה ← נוכחות ← יומי — מי מהעובדים בשטח ומי לא נרשם. מי שלא נרשם — מטפלים מיד, עד 08:00.
  2. שטח ← בוחרים אתר ← "✓ אין חריגים" או "⚠ יש חריגה" + משפט קצר. זה הדיווח היומי — עד 08:00. אחרי 08:00 נפתח חריג, ואחרי 10:00 הוא עולה לדוד.

📅 פעם בשבוע (עד יום א׳ 12:00)

שטח ← אתר ← "📅 מלא דוח שבועי" — התקדמות לפי נושאים, כוח אדם ובטיחות.

📦 מלאי (לפחות פעם ב-3 ימים)

  • מלאי ← בוחרים אתר ← מעדכנים כמויות עם + / −, ולוחצים "✓ המלאי מעודכן להיום".
  • השתמשת בחומר? ליד הפריט ← "🔧 שימוש בחומר" ← כמה נוצל, ואיפה (קומה, דירה). המלאי יורד והשימוש נרשם. נשבר או אבד? בוחרים "פחת / נזק".
  • + / − הם לתיקון ספירה בלבד. ירידה בספירה בלי רישום שימוש מופיעה בנפרד, בכרטיס "📉 צריכת חומר · 30 יום" — כדי שיהיה ברור לאן החומר הלך.
  • לכל פריט אפשר להגדיר מינימום. ירידה מתחתיו פותחת חריג — ומופיע כפתור "🛒 להזמין".
  • פריט חדש: "＋ הוסף פריט" — עדיף לבחור את השם מהרשימה שמוצעת (שמות מהקטלוג של הרכש), כדי שהקבלות יתווספו לאותו פריט.

📐 כתב כמויות מתוכנית

  • שטח ← אתר ← "📐 כתב כמויות מתוכנית" ← מעלים PDF מקורי מהמתכנן (לא סריקה, לא צילום). אפשר קובץ עם כמה עמודים — כל עמוד מקבל קומה משלו (נקראת לבד מהגיליון, אפשר לתקן).
  • המערכת מודדת את הצנרת לפי צבע/שכבה, לוקחת את הקוטר והשיפוע מהכיתוב שליד הקו (6", Ø110, 32 מ"מ, 1.5%), ואת השם מהמקרא. דוגמיות המקרא ולוגו המשרד לא נספרים.
  • בשרטוט שיוצא ישר מאוטוקאד נספרות גם זוויות וטי (הערכה — אפשר לכבות או לתקן כל מספר). בתוכנית שהצנרת בה שמורה כתמונה (הדפסה דרך PDF24) המדידה לפי צבע והדיוק כ-±10%.
  • הקשה על המפה בוחרת את הסמל/הקו שבמקום — סמל שנבחר מסומן לספירה, וכל הסמלים הזהים לו נספרים (ספרינקלרים, קולטנים…). עיגולים עם כיתוב בפנים (צירים/תגיות) כבויים כברירת מחדל.
  • נותנים שם לכל מה שמסומן. בפעם הבאה באותו אתר השמות מופיעים לבד. ארונות כיבוי, בורות ומשאבות — ב"פריטים נוספים". שומרים ← "⬇ אקסל" (גיליונות: סיכום, לפי קומה, פירוט).
  • 🔎 שאלה על הכמויות: כותבים במילים שלך, למשל כמה מטר צינור 2" בקומה 3, רשימת ספרינקלרים לפי קומה, השווה בין שתי התוכניות האחרונות. התשובה מופיעה כטבלה עם סה"כ, ו-"⬇ אקסל" מוריד אותה. יש גם אקסל של כל התוכניות באתר.
  • זו טיוטה — עוברים על המספרים לפני הזמנה.

🚨 חריגים

בקרה ← חריגים — מה חסר או באיחור באתרים שלך. חריג שלא מטופל עולה בדרג (אליך ← למנהל הבכיר ← לדוד). מטפלים — והחריג נסגר לבד.

🕒 נוכחות העובדים שלך

  • חיבור עובד (פעם אחת): בקרה ← נוכחות ← עובדים ← "🔗 שלח קישור" — נפתחת הודעת וואטסאפ בשפה של העובד. מיד אחריה שלח לו את סרטון ההדרכה.
  • שורה צבועה = לבדוק: רחוק מהאתר, אין יציאה, טלפון אחר, שעון לא תקין, משמרת ארוכה, צילום לא חי. לוחצים עליה ← "✓ אשר כמו שהוא" או מתקנים שעה — עם סיבה. הרישום המקורי נשמר.
  • "צילום לא חי"? העובד צילם במצלמה הרגילה של הטלפון ולא במצלמה שבתוך האפליקציה (קורה כשהמצלמה בדפדפן שלו לא נפתחת). בחלק מהטלפונים אפשר לבחור כך גם תמונה מהגלריה, לכן הרישום מסומן לבדיקה — השעות נספרות כרגיל. מסתכלים על התמונה: העובד, צולמה עכשיו, באתר ← "✓ אשר כמו שהוא". תמונה ישנה או של מישהו אחר ← מתקנים או מוחקים, עם סיבה.
    חוזר אצל אותו עובד? המצלמה חסומה אצלו בדפדפן — בטלפון שלו: כרום ← 🔒 ליד הכתובת ← הרשאות ← מצלמה ← "אפשר". מהרישום הבא הצילום יהיה חי.
  • שכח לצלם? מתקנים לו את השעה באותו יום, עם סיבה.
  • הקישור של כל עובד נקשר לטלפון הראשון שפותח אותו, ורק ממנו אפשר לרשום לו שעות.
  • החליף טלפון (או מחק את הדפדפן)? ליד השם ← 📱✕ ← שולחים שוב קישור. עד אז הוא יראה "הקישור כבר מחובר לטלפון אחר".
  • עובד חדש? עובדים ← הוספה ← שולחים קישור.
  • את מיקום האתר המערכת לומדת לבד מהרישומים הראשונים.
בלי סלפי אין שעות — וזה הבסיס לשכר. ימים לא סגורים מעכבים את התשלום לעובדים, לכן סוגרים חריגי נוכחות כל יום.

🛒 רכש ומלאי — איך הם מדברים

1. חסר משהו באתר — בבקרה במלאי מופיע "🛒 להזמין X" (מינימום − מלאי − מה שכבר בדרך).
↓
2. לוחצים — הרכש נפתח על הפרויקט שלך עם העגלה מוכנה. בודקים כמויות ושולחים. (אפשר גם להזמין ישר מהרכש כרגיל.)
↓
3. אישור טל (כשנדרש) ← שרון מעבירה לספק.
↓
4. בבקרה רואים את ההזמנה כ"🚚 בדרך" ליד הפריט, והחוסר לא נצבע באדום.
↓
5. הסחורה מגיעה — ברכש ← "ההזמנות שלי" ← קבלה: מצלמים תעודת משלוח ורושמים כמה הגיע מכל פריט (חסר / עודף / פגום).
↓
6. המלאי בבקרה מתעדכן לבד בכמות שהתקבלה, ונרשם ביומן הפעולות. פריט פגום לא נספר. חריגה בקבלה הולכת לשרון לזיכוי.
השימוש באתר לא יורד מהמלאי לבד — רושמים אותו ב-"🔧 שימוש בחומר" בלשונית מלאי, ומעדכנים ספירה מדי פעם.

🏢 משרד (דוד · טל · שרון)

  • משתמשים והרשאות: העיגול עם האות שלך (למעלה) ← "👥 משתמשים והרשאות" ← טלפון + תפקיד (משרד / מנהל פרויקט) + שם ← הוסף. כמה בבת אחת: "הדבקת רשימה" — שורה לכל מנהל: שם, טלפון (השם בדיוק כמו בשם המנהל באתרים). המסך מראה אילו מנהלים עוד לא רשומים. "🔗 שלח" שולח קישור כניסה בוואטסאפ. להוציא מישהו — "השבת".
  • תמונה מלאה: המשרד רואה את כל האתרים; אפשר לסנן לפי מנהל דרך בקרה ← מנהלים.
  • שכר: בקרה ← נוכחות ← חודשי ושכר ← בודקים שאין ימים פתוחים ← "⬇ ייצוא לאקסל לשכר" (סיכום + פירוט יומי).
  • חברות כ״א — דוח שעות שבועי לאישור: בקרה ← נוכחות ← חברות כ״א.
    פעם אחת: מוסיפים את החברות (שם + ₪ לשעה), ובקטע "שיוך עובדים" בוחרים לכל עובד את החברה ומספר העובד שלו אצלם (לא ת״ז).
    יש רשימה מהחברה באקסל? "📥 ייבוא רשימה מהחברה": בוחרים חברה וקובץ, עוברים על ההתאמות (✓ = זוהה לבד) ושומרים. נשמרים רק החברה ומספר העובד — טלפונים מהקובץ לא נשמרים. מי שלא נמצא בבקרה: "📋 העתק את הרשימה" ← לשונית עובדים ← הוספת כמה עובדים, ואז מייבאים שוב.
    כל יום א׳: בוחרים את השבוע שעבר ← "🔒 נעל ושלח לאישור החברה". אפשר לנעול רק כשאין ימים לבדיקה. החברה מקבלת רק שם, מספר עובד, תאריך, אתר, כניסה, יציאה ושעות — בלי תמונות ומיקומים — ומאשרת או משיגה.
    תיקון אחרי נעילה ← מופיע "השעות השתנו" ← "נעל מחדש": החברה מקבלת גרסה חדשה עם פירוט מה השתנה, והגרסה הקודמת נשמרת. דוח נעול ואישור של החברה אי אפשר למחוק או לשנות.
    משתמש לחברה: "👥 משתמשים והרשאות" ← תפקיד "חברת כ״א" ← בוחרים חברה ← הוסף ← "🔗 שלח".
  • תמונות: אחרי הפקת האקסל של חודש שהסתיים, ואחרי שחברות כ״א אישרו את כל השבועות של החודש — "🗑 מחיקת התמונות של החודש" (השעות והתיקונים נשמרים).
  • רכש: טל מאשר, שרון ממלאת "ספק בפועל" ומסמנת "הועבר לספק" בגיליון; חריגות בקבלה מסומנות לזיכוי.
  • יומן פעולות: בקרה ← יומן פעולות — מי עשה מה ומתי.

📸 עובדים — נוכחות בסלפי

  1. כל עובד מקבל קישור אישי בוואטסאפ (בשפה שלו: עברית, ערבית, הינדי, רוסית) + סרטון הדרכה.
  2. מגיע לאתר ← פותח את הקישור ← כפתור ירוק ← סלפי ← "אשר ושלח".
  3. יוצא מהאתר ← אותו קישור ← כפתור אדום ← סלפי.

אין רשת? הרישום נשמר בטלפון ונשלח לבד. העובד לא צריך סיסמה ולא SMS.
