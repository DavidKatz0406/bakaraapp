📱 שתי אפליקציות, עובדות יחד

בקרה — כל מה שקורה באתר: דיווח יומי, דוח שבועי, מלאי, נוכחות עובדים וחריגים.

רכש — הזמנת חומרים מהקטלוג, אישור, העברה לספק וקבלת הסחורה.

הן מחוברות: מה שמזמינים מופיע במלאי כ"בדרך", וכשמסמנים קבלה ברכש — המלאי בבקרה מתעדכן לבד.

פתח את הרכש

את הקישור לבקרה מקבלים בוואטסאפ מהמשרד (קישור אישי לכניסה). שמרו אותו.

🔐 כניסה לבקרה — פעם אחת

  1. פותחים את הקישור לבקרה שקיבלתם בוואטסאפ מהמשרד.
  2. מקלידים את מספר הטלפון שלך ← לוחצים "שלח קוד ב-SMS".
  3. מקלידים את הקוד שהגיע ← "כניסה". מעכשיו הטלפון זוכר אותך.

מנהל פרויקט רואה ומשנה רק את האתרים שלו. המשרד רואה הכול.

כדאי להוסיף את הבקרה למסך הבית: בתפריט הדפדפן ← "הוסף למסך הבית".

👷‍♂️ מנהל פרויקט — היום שלך באפליקציה

למעלה יש שלוש לשוניות: בקרה שטח מלאי.

☀️ כל בוקר — עד 08:00

  1. בקרה ← נוכחות ← יומי — מי מהעובדים בשטח ומי לא נרשם. מי שלא נרשם — מטפלים מיד, עד 08:00.
  2. שטח ← בוחרים אתר ← "✓ אין חריגים" או "⚠ יש חריגה" + משפט קצר. זה הדיווח היומי — עד 08:00. אחרי 08:00 נפתח חריג, ואחרי 10:00 הוא עולה לדוד.

📅 פעם בשבוע (עד יום א׳ 12:00)

שטח ← אתר ← "📅 מלא דוח שבועי" — התקדמות לפי נושאים, כוח אדם ובטיחות.

📦 מלאי (לפחות פעם ב-3 ימים)

  • מלאי ← בוחרים אתר ← מעדכנים כמויות עם + / −, ולוחצים "✓ המלאי מעודכן להיום".
  • לכל פריט אפשר להגדיר מינימום. ירידה מתחתיו פותחת חריג — ומופיע כפתור "🛒 להזמין".
  • פריט חדש: "＋ הוסף פריט" — עדיף לבחור את השם מהרשימה שמוצעת (שמות מהקטלוג של הרכש), כדי שהקבלות יתווספו לאותו פריט.

🚨 חריגים

בקרה ← חריגים — מה חסר או באיחור באתרים שלך. חריג שלא מטופל עולה בדרג (אליך ← למנהל הבכיר ← לדוד). מטפלים — והחריג נסגר לבד.

🕒 נוכחות העובדים שלך

  • חיבור עובד (פעם אחת): בקרה ← נוכחות ← עובדים ← "🔗 שלח קישור" — נפתחת הודעת וואטסאפ בשפה של העובד. מיד אחריה שלח לו את סרטון ההדרכה.
  • שורה צבועה = לבדוק: רחוק מהאתר, אין יציאה, טלפון אחר, שעון לא תקין, משמרת ארוכה. לוחצים עליה ← "✓ אשר כמו שהוא" או מתקנים שעה — עם סיבה. הרישום המקורי נשמר.
  • שכח לצלם? מתקנים לו את השעה באותו יום, עם סיבה.
  • החליף טלפון? ליד השם ← 📱✕ ← שולחים שוב קישור.
  • עובד חדש? עובדים ← הוספה ← שולחים קישור.
  • את מיקום האתר המערכת לומדת לבד מהרישומים הראשונים.
בלי סלפי אין שעות — וזה הבסיס לשכר. ימים לא סגורים מעכבים את התשלום לעובדים, לכן סוגרים חריגי נוכחות כל יום.

🛒 רכש ומלאי — איך הם מדברים

1. חסר משהו באתר — בבקרה במלאי מופיע "🛒 להזמין X" (מינימום − מלאי − מה שכבר בדרך).
↓
2. לוחצים — הרכש נפתח על הפרויקט שלך עם העגלה מוכנה. בודקים כמויות ושולחים. (אפשר גם להזמין ישר מהרכש כרגיל.)
↓
3. אישור טל (כשנדרש) ← שרון מעבירה לספק.
↓
4. בבקרה רואים את ההזמנה כ"🚚 בדרך" ליד הפריט, והחוסר לא נצבע באדום.
↓
5. הסחורה מגיעה — ברכש ← "ההזמנות שלי" ← קבלה: מצלמים תעודת משלוח ורושמים כמה הגיע מכל פריט (חסר / עודף / פגום).
↓
6. המלאי בבקרה מתעדכן לבד בכמות שהתקבלה, ונרשם ביומן הפעולות. פריט פגום לא נספר. חריגה בקבלה הולכת לשרון לזיכוי.
השימוש באתר לא מוריד מהמלאי אוטומטית — מעדכנים ספירה מדי פעם (לשונית מלאי).

🏢 משרד (דוד · טל · שרון)

  • משתמשים והרשאות: העיגול עם האות שלך (למעלה) ← "👥 משתמשים והרשאות" ← טלפון + תפקיד (משרד / מנהל פרויקט) + שם ← הוסף ← "🔗 שלח" שולח לו קישור כניסה בוואטסאפ. להוציא מישהו — "השבת".
  • תמונה מלאה: המשרד רואה את כל האתרים; אפשר לסנן לפי מנהל דרך בקרה ← מנהלים.
  • שכר: בקרה ← נוכחות ← חודשי ושכר ← בודקים שאין ימים פתוחים ← "⬇ ייצוא לאקסל לשכר" (סיכום + פירוט יומי).
  • תמונות: אחרי הפקת האקסל של חודש שהסתיים — "🗑 מחיקת התמונות של החודש" (השעות והתיקונים נשמרים).
  • רכש: טל מאשר, שרון ממלאת "ספק בפועל" ומסמנת "הועבר לספק" בגיליון; חריגות בקבלה מסומנות לזיכוי.
  • יומן פעולות: בקרה ← יומן פעולות — מי עשה מה ומתי.

📸 עובדים — נוכחות בסלפי

  1. כל עובד מקבל קישור אישי בוואטסאפ (בשפה שלו: עברית, ערבית, הינדי, רוסית) + סרטון הדרכה.
  2. מגיע לאתר ← פותח את הקישור ← כפתור ירוק ← סלפי ← "אשר ושלח".
  3. יוצא מהאתר ← אותו קישור ← כפתור אדום ← סלפי.

אין רשת? הרישום נשמר בטלפון ונשלח לבד. העובד לא צריך סיסמה ולא SMS.
